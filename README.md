# Chart.js Pie Chart with Outside Labels

A pie chart built with Chart.js 3.6.0 and the chartjs-plugin-labels-dv plugin in plain HTML, CSS and JavaScript.

## Getting started

Open `index.html` in your browser. No build step or installation is needed, Chart.js and the plugin are loaded from a CDN.

## Project structure

```
.
├── index.html
├── style.css
└── script.js
```

`script.js` is split into three blocks: data, config and render.
